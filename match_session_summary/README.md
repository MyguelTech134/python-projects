# Match Session Summary

A simple Python program that summarizes five matches.

I made this project to practice loops, conditions, counters, and calculations.

## How it works

For each match, enter:

- W for a win or L for a loss.
- The time played in minutes, using a positive whole number.

After five matches, the program shows wins, losses, win rate, total minutes, and average time per match.

This version assumes valid input.

## How to run

With Python 3.12 or newer installed, open this folder in a terminal and run:

```bash
python match_session_summary.py
```

## Example

For these matches:

| Result | Minutes |
|---|---|
| W | 20 |
| L | 25 |
| W | 15 |
| W | 30 |
| L | 10 |

The summary shows:

- 3 wins and 2 losses
- 60.0% win rate
- 100 minutes played
- 20.0 minutes per match
